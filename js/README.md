# Berthrand Kevin | Portfolio Website

A modern, responsive portfolio website for Berthrand Kevin, a Creative Technologist and UX Designer based in Cape Town, South Africa.

## 📁 Folder Structure

## 🚀 Features

- **Responsive Design** – Works on desktop, tablet, and mobile
- **Project Filtering** – Filter work by category (Design/Dev/UX)
- **Contact Form** – Front-end validation and submission simulation
- **Modern UI** – Clean gradients, smooth animations, and consistent spacing
- **Mobile Navigation** – Hamburger menu for smaller screens

## 🎨 Color Palette

- Primary: `#5B4B8A` (Purple)
- Secondary: `#FF7E6B` (Coral)
- Accent: `#FFD166` (Yellow)
- Dark: `#2B2D42`
- Gray Light: `#EDF2F4`

## 📦 Running Locally

1. Download or clone this folder
2. Open any `.html` file in your browser
3. No build steps or dependencies required!

## 📄 Pages

- **Home** – Hero section, passions, location, and quote
- **About** – Bio, likes, and skills/tools
- **Projects** – Gallery with filterable project cards
- **Contact** – Form and contact information

Berthrand Kevin is a Creative Technologist based in **Cape Town, South Africa**. He specializes in UX/UI design and front-end development, and is passionate about creating meaningful digital experiences.
